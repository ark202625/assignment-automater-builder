# Assignment Automater Cloud Agent Rules

1. Inspect before modifying.
2. Back up files before modification.
3. Never delete project files without a recoverable backup.
4. Test every change.
5. Never mark a task complete without test evidence.
6. Never invent assignment requirements.
7. Assignment PDFs are runtime inputs and are never hardcoded.
8. Practical and Project outputs must remain separate.
9. Preserve original assignment files.
10. Remove temporary artifacts before release.
11. Roll back catastrophic failed changes.
12. Never store API keys or secrets in Git.
